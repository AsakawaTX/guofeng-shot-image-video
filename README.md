# guofeng-shot-image-video

古风仙侠电影感分镜：一句画面想法，变成能直接用的生图提示词；一张分镜图，变成让它动起来的视频提示词。

## 能做什么

### 1. 生图提示词

你描述想要的古风仙侠画面，哪怕只有一句话，比如「月下和仙子喝茶」，Agent 会帮你：

- **拓展分镜**：从内置的镜头预设里选出最贴合的拍法（第一人称伸手互动、过肩、隔窗窥视、极远大全景、鸟瞰、贴地仰拍、御剑跟随、细节特写等），再把视角、机位、倾斜、近中远三层、前景遮挡、光的方向和尺度写具体。
- **补全画面内容**：你说了的照用，没说到的用内置预设补上，比如云海上的宫阙、瀑布、月夜灯笼、茶具香炉、纱帘。
- **固定画风**：统一接上一段电影感画风描述，保证一整组分镜像同一部片子。

一次出多个分镜时，会自动换着用不同的拍法，相邻的镜头不重复，剪在一起不会腻。

### 2. 视频提示词

把生成好的分镜图连同提示词一起交给 AI 视频生成模型。因为图已经定好了画面和风格，视频提示词不再重复描述画面，只写：

- 图里哪些东西在动、怎么动：风吹纱帘和衣袖、云在流、瀑布在落、灯火摇晃、人物一个小幅的姿态变化
- 图里看得见的东西发出什么声音：风声、布料的扑簌声、瀑布的轰鸣、灯笼纸的沙沙声
- 不能变的东西：单镜头不切换，构图、人物和光影保持原样，手和脸不变形

默认时长 5 秒。视频不生成背景音乐和人声，方便后期统一配乐。

## 为什么这样设计

这类古风氛围短视频，核心在图，视频只是在图上加入小幅的动态。

而决定一张图高不高级的，不是古风元素堆得多不多，而是镜头感：像有人身处现场、顺手拍下的电影画面，而不是一张摆好的海报。所以这个 skill 把最多的功夫花在分镜上。

## 文件结构

```
guofeng-shot-image-video/

└── references/
    ├── shot-presets.md          镜头预设：26 种适合宏大仙侠场景的拍法
```

## 使用方法

把整个文件夹放进你的 Agent 的 skills 目录，然后直接说你想要的画面，或者把分镜图发给它要视频提示词。

生图提示词为英文，长度控制在 900 个字符以内。
